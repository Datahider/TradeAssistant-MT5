# TradeAssistant for MT5

Советник для сопровождения уже открытых позиций на netting-счете MT5.

## Что делает советник

1. Отслеживает появление новой позиции по текущему символу.
2. Если появилась новая позиция минимальным лотом, считает стартовый `SL` по `ATR`.
3. Ставит стартовый `SL`.
4. Считает допустимую доливку по ограничению `RiskMoney`.
5. Доливает позицию по текущей рыночной цене, не превышая `MaxLot`.
6. На каждом новом баре:
   - подтягивает `SL` по `ATR`, если `UseATRTrailing = true`
   - пытается сделать safe-доливку, только если текущий `SL` уже в прибыли
   - закрывает позицию по лимиту баров

## Ограничения

- Поддерживается только `netting`-счет.
- Советник работает только с одной позицией по текущему символу.
- Если новая позиция открыта не минимальным лотом, первичный автодонабор не выполняется.

## Входные параметры

- `RiskMoney` — целевой денежный риск на позицию.
- `MaxLot` — максимальный суммарный объем позиции.
- `ATRPeriod` — период `ATR`.
- `ATRMultiplier` — множитель `ATR` для расчета `SL`.
- `CloseAfterBars` — закрытие позиции после указанного количества баров.
- `UseATRTrailing` — включение/выключение трейлинга по `ATR`.

## Логика стартового автодобора

Если по символу появляется новая позиция минимальным лотом:

1. Берется `ATR` по предыдущему закрытому бару.
2. Рассчитывается стартовый `SL` от средней цены позиции:
   - `BUY`: `open_price - ATR * ATRMultiplier`
   - `SELL`: `open_price + ATR * ATRMultiplier`
3. Считается риск уже открытого минимального лота до этого `SL`.
4. Считается остаток допустимого риска до `RiskMoney`.
5. По текущей цене рынка рассчитывается добавочный объем на этот остаток риска.
6. Доливка ограничивается:
   - минимальным лотом брокера
   - шагом лота брокера
   - `SYMBOL_VOLUME_MAX`
   - пользовательским `MaxLot`

## Логика safe-доливки на новом баре

Safe-доливка выполняется только если текущий `SL` уже в прибыли относительно средней цены позиции:

- для `BUY`: `SL > POSITION_PRICE_OPEN`
- для `SELL`: `SL < POSITION_PRICE_OPEN`

Добавочный объем рассчитывается так, чтобы после доливки текущий `SL` все еще оставался в плюсе.

## Расчет риска

Советник использует `OrderCalcProfit()`, а не приближенный расчет через `tick value`.

Это используется:

- для расчета стартового целевого объема
- для расчета первичной автодоливки по остатку риска

## Логи

Советник пишет в лог:

- обнаружение существующей позиции при старте
- постановку стартового `SL`
- результат автодоливки
- результат трейлинга
- результат закрытия по лимиту баров
- `Retcode` при отказе торговых операций
